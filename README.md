## 🛠️ Usage

Each tool is self-contained. Navigate to the tool directory and check its README for specific usage instructions:

```bash
cd tools/<tool-name>
python <script>.py --help
```

## 🤝 Contributing

Contributions are welcome! If you have a useful script for scientific computing:

1. Create a new directory under `tools/` with a descriptive name
2. Include a `README.md` describing what the script does and how to use it
3. Submit a Pull Request
